# Кадастровые данные в структурированном виде для ваших систем

Сервис предоставляет открытые кадастровые данные в структурированном виде для использования в ваших системах и ИИ-агентах.

## Способы получения информации

Сервис предоставляет данные несколькими способами:

- **API** — документация по API: [https://cadastral.rulink.io/api/openapi](https://cadastral.rulink.io/api/openapi)
- **MCP** — подключение по протоколу MCP: [https://cadastral.rulink.io/mcp](https://cadastral.rulink.io/mcp)
- **Веб-интерфейс** — просмотр данных: [https://cadastral.rulink.io](https://cadastral.rulink.io)

## API

Предоставляет данные через REST API запросы.  
Для получения данных необходимо получить API-ключ. Для получения API-ключа обратитесь по адресу [hello@rulink.io](mailto:hello@rulink.io)

Полное описание API доступно по адресу: [https://cadastral.rulink.io/api/openapi](https://cadastral.rulink.io/api/openapi?utm_source=support&utm_medium=cadastral)

Реализовано несколько режимов работы API:
- **SYNC** — запросы в синхронном режиме, когда ответ приходит в течение нескольких секунд.
- **QUEUE** — запросы в асинхронном режиме, когда ответ регистрируется в очереди и может быть получен позже.

## MCP

Предоставляет данные запросами к MCP Server.  
Подключите MCP Server к вашему ИИ-приложению и запрашивайте кадастровую информацию из чата с ИИ или через агентов.  

Для обращения к MCP необходимо получить OAuth токен. Для получения токена обратитесь по адресу [hello@rulink.io](mailto:hello@rulink.io).  
Адрес MCP сервера: [https://cadastral.rulink.io/mcp](https://cadastral.rulink.io/mcp?utm_source=support&utm_medium=cadastral)

!!! note 
    Для экономии токенов количество объектов по адресу ограничено 10 объектами. Если по адресу найдено больше объектов, необходимо уточнить адрес до дома или квартиры.

!!! note
    Для экономии токенов кадастровые данные сокращены до основных полей (например, убраны пустые поля, поля структурированного адреса и т.п.).    
    Проверено, что сокращённые данные позволяют получить достаточную для анализа информацию

## Как это работает 

Все методы реализуют 2 типа запросов:
- **по кадастровому номеру** — для получения информации об объекте недвижимости по его уникальному идентификатору.
- **по адресу** — для получения кадастровых номеров объектов недвижимости по адресу, для последующего получения информации по кадастровому номеру.

??? abstract "Что такое кадастровый номер"
    Кадастровый номер — это уникальный идентификатор объекта недвижимости, присваиваемый Росреестром.
    Номер имеет 4 части, разделённые двоеточием, и выглядит как 77:01:0450400:1233.

!!! note "Совет"
    Если адрес указан с точностью до дома, результатом будет список всех квартир и других зданий по этому адресу.

## Ограничения 

Справочные данные по кадастровым объектам могут иметь ограничения по точности и задержку обновления. Пользователи должны учитывать это при использовании данных в своих системах и ИИ-агентах.
